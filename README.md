# GAME2014 Mobile Development

**Unity mobile labs and checkpoint-platformer work** from a mobile development course, including joystick input, Cinemachine, animations, and checkpoint systems.

---

## Status

Educational multi-lab repository (`Lab4/` and related folders). Coursework, not a shipped title.

## Tech stack

| Area | What it uses |
|---|---|
| Engine | Unity |
| Language | **C#** |
| Camera | **Cinemachine** (added in lab history) |
| Input | Joystick Pack (third-party) |

## What's in the project

| System | Key files (Lab4) |
|---|---|
| Game flow / checkpoints | `Lab4/Assets/_Scripts/GameController.cs`, `Checkpoint.cs`, `DeadPlane.cs` |
| Animation states | `Lab4/Assets/_Scripts/AnimationStates.cs` |
| Joystick package | `Lab4/Assets/ExternalAssets/Joystick Pack/` |

## About this repository

Public coursework history across multiple labs. Third-party joystick assets remain under their own licenses.
